      Como funciona

      Os 41 filmes do site do livro Fundação Bradesco 70 anos. Cole o link de cada filme e marque o status: o link vai para o site e o status aparece para o cliente no cronograma, sozinhos. Quando um filme vai para o cliente (V2 ou online), use “Mensagem para o cliente”: ela já sai com o link do filme, o cronograma e o prazo do retorno.
